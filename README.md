# Smart Waste Management Using Data Mining and ML

### Description
Our main aim is to build a system that:
1. Analyses garbage generation patterns.
2. Identifies areas generating more waste.
3. Classifies garbage bins based on their waste levels.
4. Groups bins according to waste generation patterns.
5. Predicts which bins require immediate garbage collection.

### Technologies used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook
